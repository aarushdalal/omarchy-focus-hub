# Changelog

All notable changes to `omarchy-focus-hub` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-08

### Added
- Initial clean public release for Omarchy 4.0.2 / Arch Linux.
- Pomodoro session controller with customizable focus and break intervals.
- Ambient sound generators and celebratory reward audio.
- Strict opt-in application/domain distraction controls without silent termination.
- Comprehensive safe user installer script (`install.sh`) supporting `--dry-run`.
- Full security exclusions, sanitized configurations, and complete documentation.
